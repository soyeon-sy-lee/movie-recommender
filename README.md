# 3 in 3 - 인생영화 추천기

인생영화 3편을 입력하면 영화의 장르·정서·서사 태그를 바탕으로 취향을 분석하고, 다음에 볼 영화 3편을 추천하는 웹 애플리케이션입니다.

**현재 상태:** 기능 데모를 위한 GitHub Pages 배포  
**구현 방식:** HTML, CSS, JavaScript 기반 정적 웹앱

## Demo

**서비스:** https://soyeon-sy-lee.github.io/movie-recommender/

**사용 흐름:** 인생영화 3편 검색 및 선택 → 취향 태그 분석 → 추천 영화 3편과 추천 이유 확인 → 다른 추천 보기 또는 개별 피드백 반영

화면에 표시되는 유사도는 입력한 영화와 추천 후보 사이의 태그 일치도를 상대적으로 환산한 값입니다. 실제 만족도, 예상 평점 또는 관람 확률을 의미하지 않습니다.

## 주요 기능

- 한글·영문 영화 제목과 한글 초성 검색을 지원하는 자동완성
- 입력한 영화들의 공통 태그를 이용한 취향 분석
- 영화 포스터, 유사도 점수와 추천 이유를 함께 보여주는 영화 3편 추천
- 최대 3세트의 추천 결과를 탐색할 수 있는 `다른 추천 보기`
- `이미 봤어요`를 선택한 영화의 개별 교체
- 👍·👎 피드백을 반영한 사용자 맞춤 추천
- 데스크톱과 모바일 환경을 고려한 화면 구성

## 데이터와 추천 로직

| <nobr>항목</nobr> | 내용 |
| --- | --- |
| <nobr>데이터 출처</nobr> | MovieLens `ml-latest-small`, Wikidata 공개 정보 |
| <nobr>사용 데이터</nobr> | 영화 제목, 장르, 사용자 태그, 한국어 제목과 IMDb 연결 정보 |
| <nobr>데이터 준비</nobr> | MovieLens와 Wikidata의 공개 데이터를 결합해 영화 검색과 추천에 필요한 데이터를 구성 |
| <nobr>추천 입력</nobr> | 사용자가 선택한 인생영화 3편 |
| <nobr>추천 방식</nobr> | 입력 영화의 태그 점수, 후보 영화와의 태그 일치도, 새로운 분위기나 소재에 대한 추가 점수, 개봉 시기와 사용자 피드백을 반영해 추천 순위 결정 |
| <nobr>피드백 저장</nobr> | 사용자의 영화 평가와 이미 본 영화 정보를 현재 브라우저에 저장 |

입력한 영화마다 포함된 태그에 가중치를 부여하고, 세 영화의 태그 점수를 합산합니다. 합산 점수가 높은 태그를 사용자의 주요 취향으로 해석하고, 추천 후보는 이 취향 태그와의 일치도를 바탕으로 점수를 받습니다.

입력한 취향과 잘 맞으면서도 새로운 분위기나 소재를 가진 영화에는 소폭의 추가 점수를 부여합니다. 또한 새로운 작품을 발견할 수 있도록 비교적 최근에 개봉한 영화에도 추가 가중치를 적용합니다.

사용자가 👍 또는 👎 평가를 남기면 해당 영화와 영화가 가진 태그에 대한 선호도가 현재 브라우저에 저장되고, 이후 추천 결과에 반영됩니다.

현재 버전은 여러 사용자의 평점 데이터를 학습하는 추천 모델이 아닙니다. 영화 태그와 현재 사용자의 피드백을 바탕으로 추천 순위를 정하는 방식입니다.

## 사용 방법

1. 인생영화 입력란에서 좋아하는 영화 3편을 검색하고 선택합니다.
2. `추천 받기`를 눌러 취향 분석과 추천 영화 3편을 확인합니다.
3. 각 영화의 포스터, 유사도 점수, 취향 태그와 추천 이유를 확인합니다.
4. 추천 결과가 마음에 들거나 들지 않는 경우 👍 또는 👎 피드백을 남깁니다.
5. 이미 본 영화는 `이미 봤어요`를 눌러 다른 영화로 교체합니다.
6. `다른 추천 보기`를 눌러 최대 3세트의 추천 결과를 탐색합니다.

## 프로젝트 한계

- 현재 추천은 영화 태그와 현재 사용자의 피드백을 이용한 가중치 기반 방식이며, 여러 사용자의 평점 데이터를 학습하는 추천 모델은 아닙니다.
- 입력한 영화의 태그가 부족하거나 부정확하면 취향 분석과 추천 품질이 낮아질 수 있습니다.
- 유사도 점수는 현재 추천 후보 안에서 계산된 상대 점수이며 영화의 객관적인 품질이나 만족도를 나타내지 않습니다.
- 최근 영화의 탐색성을 높이기 위해 비교적 새로운 작품에 추가 가중치를 부여하므로 오래된 영화가 상대적으로 적게 노출될 수 있습니다.
- 사용자 피드백은 현재 브라우저에만 저장되며 다른 기기나 브라우저와 동기화되지 않습니다.
- 브라우저의 사이트 데이터를 삭제하면 저장된 평가와 이미 본 영화 기록도 함께 삭제됩니다.
- 공개 데이터에 포함되지 않거나 한국어 제목을 확인할 수 없는 영화는 검색 및 추천 후보에서 누락될 수 있습니다.

## 향후 계획

- 사용자 평가를 바탕으로 최근 영화와 이전 영화의 추천 비율을 자동으로 조정하는 학습 구조 구현
- 검색·추천 가능한 영화 데이터 확대
- 영화별 태그 정제와 추천 이유 품질 개선
